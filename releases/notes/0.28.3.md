## 修复
- 修复 Codex app-server 返回同一 thread 的多个 rollout 路径时，会话状态在处理中与已完成之间抖动并重复播放完成音效的问题
- 完成音效和完成弹窗改用稳定的 turn / assistant item 完成键；同一次完成无论被轮询重放多少次都只消费一次，新 turn 完成仍会正常提示
- 音效状态机统一由会话监控层持有，切换刘海与悬浮胶囊时不再因视图重建重置去重状态
- 修复切换 macOS Space 后刘海窗口偶尔不再显示的问题
- 修正 Claude token 统计：`cache_read` 不再重复计入 input，并按 message ID 去重

## 改进
- 同一工作目录中的多个并发会话现在会保持独立，不再互相覆盖或因列表排序变化产生伪状态边沿
- Codex `thread/list` 现在按 thread ID 选择 active / 更新 / 可读的 canonical rollout，并按 rollout 路径隔离恢复缓存

## 说明
- Sparkle build 号提升到 `76`，版本号提升到 `0.28.3`
- 正式发布产物通过 GitHub Actions 完成 Developer ID 签名与 Apple 公证

## Fixes
- Fixes repeated completion sounds caused by Codex app-server rows for the same thread oscillating between processing and completed rollout snapshots
- Uses stable turn and assistant-item completion keys for both completion sounds and popups, so replaying one completion stays silent while a new turn can still notify
- Moves sound-event state into the shared session monitor so switching between the notch and floating capsule does not reset deduplication
- Restores notch visibility after switching macOS Spaces
- Corrects Claude token accounting so `cache_read` is not counted again as input and messages are deduplicated by ID

## Improvements
- Keeps concurrent sessions in the same workspace independent instead of allowing list ordering to create false state edges
- Canonicalizes Codex `thread/list` rows by thread ID and isolates recovery caches by rollout path

## Notes
- The Sparkle build number is now `76`, and the app version is now `0.28.3`
- Production artifacts are Developer ID signed and Apple-notarized through GitHub Actions
