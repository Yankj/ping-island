# AgentIsland 首次启动体验

## 目标

AgentIsland 是 Ping Island 的体验增强预览构建。首次启动必须同时做到两件事：让新用户快速理解产品价值，以及让它在名称、包体与界面上和原版 Ping Island 清楚区分。

本实现借鉴 Vibe Island 的节奏与信息组织，不复制其代码、音频、图片或专有资源。

## 流程

1. **品牌揭幕**：先播放独立的光束、图标与状态岛启动动画，并配套一段 6 秒原创立体声仪式音；升级到新的欢迎体验版本时也会完整展示一次。
2. **统一视野**：说明 Claude、Codex、Gemini 与 IDE 会话如何汇入同一个状态岛。
3. **语义声效**：解释十个运行阶段各自使用不同反馈，并在翻页时播放独立阶段提示音。
4. **精准返回**：说明如何回到匹配的终端、IDE 窗口、标签页或会话。
5. **安静交互**：说明 150 ms Hover、离开容错、焦点抑制与“减少动态效果”。
6. **用户选择**：选择顶部状态岛或悬浮宠物，并明确选择是否发送匿名统计。
7. **Hooks 授权**：首启窗口完成后，才显示独立的 Hooks 安装说明。默认安装、自定义和跳过都由用户明确选择。

首屏可以“跳过介绍”直达选择页；其余页面都可以返回。开启 macOS“减少动态效果”时，位移和缩放过渡会降级为静态或淡入淡出。

## 声音

首启音由 `AppSoundCueRenderer` 在本地生成 48 kHz 双声道 PCM，不包含 Vibe Island 的音频采样。仪式音由环境铺底、上行主题和品牌落点三个阶段组成；五张后续页面各有独立短提示。日常反馈覆盖会话开始、任务确认、需要介入、完成、错误、上下文限制、闲置提醒、额度预警、额度恢复和连续提交。合成波形会预渲染为内存 WAV，再交给 `AVAudioPlayer` 预热和播放，避免首次输出配置变化打断首播。

## 品牌与包体

- 用户可见名称：`AgentIsland`
- 本地预览 Bundle ID：`com.agentisland.preview`
- 首启界面持续显示“基于 Ping Island 的体验增强预览版”
- 应用图标使用原创的玻璃折叠 `A` 与横向状态岛符号；母版、AppIcon 全尺寸资源和本地打包用 ICNS 均保存在仓库中
- Finder 图标、运行时应用图标、欢迎页、设置侧栏、关于页与更新页统一从 `CFBundleIconFile` 指向的 AgentIsland ICNS 读取
- 预览安装包使用 `AgentIsland.app`、`AgentIsland-<version>-preview-<arch>.dmg` 和对应 ZIP 文件名

项目内部仍保留部分 `PingIsland` 技术名称（例如 Xcode target、Bridge 协议和既有配置目录），以保持开源上游兼容；这些不作为用户可见产品名称。

由于两个构建共用 Hooks、`/tmp/island.sock` 和本地 Bridge，AgentIsland 会阻止它与原版 Ping Island 同时运行，并显示明确提示。Hook 的内部托管标记保持上游兼容，用户选择安装时会更新已有托管项，而不是叠加一套重复回调。

设置侧栏底部固定显示“退出 AgentIsland”。顶部状态岛与悬浮宠物的右键菜单均提供“打开设置”和“退出 AgentIsland”，避免为了退出应用深入多层设置。

## 验证

- 合成音测试覆盖格式、有限样本、时长和峰值。
- 本地预览包需通过 plist、代码签名、ZIP、DMG 和启动冒烟验证。
- 界面验证需至少覆盖首屏、能力页、选择页和“减少动态效果”。
